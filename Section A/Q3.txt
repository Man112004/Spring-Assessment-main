Basic Authentication:

Basic Authentication protects secure API endpoints using a username and password.
The client sends credentials in the HTTP Authorization header.
Spring Security checks the credentials before allowing access.
We can configure Spring Security using a SecurityFilterChain bean.
If authentication fails, the server returns HTTP 401.

Validation:

@Valid activates request-data validation.
@NotBlank ensures a string is not empty or blank.
@Min(1) ensures a numeric value is at least 1.

Example:
public class OrderRequest {

    @NotBlank
    private String customerName;

    @Min(1)
    private int quantity;
}
